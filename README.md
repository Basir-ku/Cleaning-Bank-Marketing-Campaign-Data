# Cleaning-Bank-Marketing-Campaign-Data
This project aims to clean and transform data from a bank marketing campaign to prepare it for storage in a PostgreSQL database. The cleaned data will adhere to a specific structure and data types defined by the bank, enabling efficient data management for current and future campaigns.  The process involves cleaning inconsistencies, converting data types, and splitting the data into three separate CSV files: `client.csv`, `campaign.csv`, and `economics.csv`.
